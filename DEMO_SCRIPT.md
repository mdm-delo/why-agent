# 2-minute demo script (screen: web demo at localhost:8765)
- **0:00–0:15 Problem.** "One founder plus AI agents make 10+ decisions a day about money, grants and partners. Nobody remembers why, so the same arguments keep coming back."
- **0:15–0:35 Idea.** "Why-Agent is a decision avatar. It decides using the founder's own rules, P1 to P12, learned from his answers, and every decision comes with its full why."
- **0:35–1:00 Scenario 1, paid API credits.** Click the button, then Decide. Point to the action, the rule P11, the evidence (balance, zero credits, free tiers already running), the alternatives and their scores, and the 3/3 votes.
- **1:00–1:25 Scenario 3, "sign a wallet transaction".** The option where the agent signs is shown BLOCKED by hard rule P7. The action becomes "prepare a draft, ask the founder". Say: "The agent explains the boundary it won't cross."
- **1:25–1:45 Scenario 5, memory.** A repeated question shows "Decided before" with the past card. Then turn on LLM narration: "The LLM only narrates. The decision stays deterministic and auditable."
- **1:45–2:00 Close.** Show the Yes / No / Later buttons: "The human gives the final yes." Next steps: Zetaris as the data layer, Meterless reviewers, Telegram.
